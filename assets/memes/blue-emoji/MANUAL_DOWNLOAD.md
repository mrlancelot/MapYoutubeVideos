# Blue Emoji Manual Download

Bluemoji.io requires JavaScript to render images. 
Visit https://bluemoji.io and right-click > Save Image for each:

## Required Blue Emojis:
1. Crying/Desperate - fountains-of-tears
2. Smug - smug
3. Thinking - thinking-face
4. Angry/Frustrated - frustrated
5. Scheming - troll-face
6. Shocked - freaked-out
7. Sad - weary-face
8. Suspicious - suspicious-big-eye
9. Pleading - pleading-face
10. Evil Grin - making-an-argument

## Quick Download:
1. Go to https://bluemoji.io
2. Right-click each emoji
3. Save Image As...
4. Save to this folder
