# Blue Emoji Download Instructions

The blue emojis must be downloaded manually from https://bluemoji.io/

## Required Emojis for All 5 Videos:

1. **Angry** - https://bluemoji.io/emoji/angry
2. **Crying/Desperate** - https://bluemoji.io/emoji/desperate
3. **Flushed** - https://bluemoji.io/emoji/flushed
4. **Smug** - https://bluemoji.io/emoji/smug
5. **Scheming** - https://bluemoji.io/emoji/scheming (rubbing hands)
6. **Lipbite** - https://bluemoji.io/emoji/lipbite
7. **Shocked** - https://bluemoji.io/emoji/shocked
8. **Sad** - https://bluemoji.io/emoji/sad

## How to Download:
1. Visit each URL above
2. Right-click on the emoji image
3. Select "Save Image As..."
4. Save to this folder with the name shown above (e.g., `angry.png`)
